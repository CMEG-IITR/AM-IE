# Directed Energy Deposition (DED)

## Synonyms

- **Laser Power**: deposition power, beam power
- **Travel Speed**: scan speed, traverse speed, deposition speed
- **Wire Feed Rate**: feed rate, wire feed speed

## Extraction notes

- Wire-fed and powder-fed DED report different feedstock parameters — check which feedstock type is used before assuming which parameter set applies.
- Travel speed and wire/powder feed rate are usually reported as a paired ratio (feed-to-travel-speed ratio) — extract both values even if only the ratio is emphasized.
